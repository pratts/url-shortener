tidylnk

A small URL shortener, built as a hobby project.

TidyLnk turns long links into short ones like tidylnk.com/aZ3kP9q and counts how often they are opened. It is a personal project for learning how to build and run a small service end to end: not a commercial product, and with no guarantees.

Links

  • Admin panel: create and manage short links
  • Backend source: Go, PostgreSQL and Redis
  • Admin panel source: React and TypeScript

Built with

Go (Fiber), PostgreSQL and Redis on Railway; a React admin panel on Vercel; DNS on Cloudflare.

Short links on this domain lead to other websites, which TidyLnk does not control. To report an abusive link, open an issue on GitHub.
